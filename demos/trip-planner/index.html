여행 계획 초안을 상품 견적으로 이어 붙이는 워크플로

개인 여행자가 조건을 입력하면 생성 요청만 접수(202)되고, 실제 파이프라인은 별도 워커가 실행합니다. 워커가 만든 결과는 검증에 통과한 것만 영속 버전으로 저장되고, 이후 수정·리믹스로 새 버전을 쌓습니다. 여행사 담당자는 본인 소유 일정 하나를 골라 판매용 상품 견적으로 바꿉니다.

이 화면은 위 흐름을 브라우저에서 재현한 가짜 데모입니다. 서버, 데이터베이스, 지도·경로 API, 모델 호출은 없습니다. 운영 도메인과 회사명은 공개하지 않고 확인된 기능만 설명합니다.

이 화면이 다루는 업무 문제

생성 요청과 실제 실행의 분리

요청은 즉시 접수만 되고 응답합니다. 무거운 생성은 백그라운드 워커가 맡아 화면이 요청 중에도 멈추지 않습니다.

실패한 결과는 남기지 않기

파이프라인 검증에 실패한 초안은 버리고, 성공한 결과만 버전으로 저장합니다. revision 이력이 오염되지 않습니다.

본인 소유 일정만 판매로 전환

여행사 직원은 소유권을 확인받은 일정만 상품 견적으로 바꿀 수 있고, 견적 라인은 비용 엔진 결과를 그대로 사용합니다.

조작 가능한 데모

순서대로 눌러 보세요. 1 → 2 → 3 → 4번 단계가 서로 이어집니다.

1. 여행자 조건 입력 → 생성 요청 접수

요청을 넣으면 202 접수 번호가 먼저 발급되고 파이프라인은 대기합니다. 지역·일수·테마·예산을 바꿔 보고 결과 차이를 확인해 보세요.

HTTP 202 Accepted - 접수만 완료되고 파이프라인은 백그라운드 워커가 이어서 실행합니다.

2. 백그라운드 워커 실행 로그

각 단계는 원본 저장소의 구성 요소를 그대로 대응시킵니다. 마지막 검증 단계가 통과해야 버전 저장까지 이어지고, 실패하면 저장이 중단됩니다.

대기 중

    3. 저장된 버전과 일정 리믹스

    검증을 통과한 결과만 버전 목록에 쌓입니다. 시간과 포함 여부를 바꾼 뒤 저장하면 새 버전이 생기고, 예전 버전은 그대로 남습니다.

    버전 이력

    저장된 버전이 없습니다.

    실행한 결과가 여기에 표시됩니다.

    4. 소유 일정을 상품 견적으로 전환

    소유권이 있는 일정만 선택할 수 있습니다. 비용 엔진 결과를 판매 견적 라인으로 바꾸고 마진을 더해 판매가를 냅니다. 링크 생성은 화면 안에서만 이루어지며 실제 발송은 하지 않습니다.

    보유한 일정이 없으면 견적을 만들 수 없습니다.

    고정 버전 공유

    현재 날짜와 순서를 고정한 읽기 전용 보기를 만듭니다. 나중에 일정을 바꿔도 공유된 고정 버전은 변하지 않습니다.

    원본에서 확인한 구현

    README와 의존성 목록, 공개 소스 구조만 보고 적은 내용입니다. 성과 수치는 없습니다.

    • 생성은 202 접수와 별도 워커 실행으로 나뉘며, 성공한 결과만 영속 버전으로 저장합니다.
    • 개인 일정의 저장, 수정, 공유, 리믹스와 여행사 직원의 상품 견적 전환이 분리된 화면으로 구현되어 있습니다.
    • 백엔드는 FastAPI, Pydantic, SQLAlchemy, Alembic, JWT 기반 인증, PostgreSQL 드라이버로 구성되어 있습니다.
    • 프런트엔드는 React, React Router, Leaflet 기반이며, 생성 상태를 SSE로 수신하는 구성이 있습니다.
    • 실행 모듈은 런타임, 경로 추정, 시간 배치, 비용 산정, 파이프라인 루프로 나뉘고, 외부 키 없이도 합성 자료와 고정 경로로 동작합니다.
    • 지식 폴더에 지역 후보 자료와 변환 어댑터가 있고, 지식 조회 단계를 통해 후보를 가져옵니다.

    데모와 실제 구현의 차이

    • 서버가 없습니다. 이 데모의 접수·워커·버전 저장은 브라우저 메모리에서만 동작하며 새로고침하면 사라집니다.
    • 경로와 지도를 계산하지 않습니다. 실제 서비스는 조회 응답으로만 경로를 제공하지만 이 화면에는 이동 시간이 모두 가상의 고정값입니다.
    • 모델을 호출하지 않습니다. 후보를 고르는 규칙은 모두 이 데모 파일 안의 결정적 로직이며 실제 모델 추론 결과가 아닙니다.
    • 인증과 권한 검사가 없습니다. 소유권 확인, 공유 토큰 검증, 접근 차단은 서버가 담당하며 이 데모에는 없습니다.
    • 데이터는 모두 합성입니다. 지역명, 시설명, 요금, 일정은 실제 장소와 무관하게 만들어진 값입니다.
    • 운영 판단은 공개하지 않습니다. 실제 서비스 주소, 회사명, 배포 구성, 내부 문서는 이 데모에 포함하지 않았습니다.
