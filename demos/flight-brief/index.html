항공권 예약 준비 자동화 — 결제 직전 검증까지

여행 대장과 고객이 메신저로 주고받는 항공권 안내 문구에는 날짜 범위, 시각, 공항, 항공사, 예약처와 가격이 한 덩어리로 섞여 들어옵니다. 이 데모는 그 문구를 구조화된 주문서로 바꾸고, 탑승자 여권 정보를 채운 뒤, 결제 단계로 넘어가기 전에 막아야 하는 조건을 검사하는 흐름을 그대로 재현합니다.

회사 / 서비스명 비식별 모든 인물·여권·가격은 가상 값 폼 전송 없음 · 저장 없음

1메신저 문구 붙여넣기

날짜 범위(12.1~5), 오전 8:40, 공항, ○○항공, Trip.com ₩493,500, 인원수를 자유 문구에서 꺼냅니다.

※ 이 데모는 브라우저 안에서만 계산합니다. 입력 문구는 어디로도 전송되지 않고 새로고침하면 사라집니다.

예약처 / 표시 가격

표시 가격은 참고값입니다. 실제 결제 금액은 결제 시점에 달라질 수 있습니다.

탑승자 여권 정보 (합성)

인원수에 맞춰 폼이 생성되고, 여권 만료일은 합성 값이 미리 들어 있습니다. 값을 고치면 검증 결과가 바로 다시 계산됩니다. 여권번호는 입력해도 화면에는 마스킹되어만 표시되고 어디에도 전송·저장되지 않습니다.

3결제 전 검증 결과

    4주문서 요약 & 검색 링크

    사람이 읽을 수 있는 주문서와, 날짜·노선이 채워진 검색 결과 URL을 만듭니다.

    주문서

    예약처 검색 URL

    가격 비교에는 출발지·도착지·가는 날만 있으면 충분합니다. 선택과 결제는 사람이 진행해야 하므로, 이 데모는 URL 문자열만 만들어 보여주고 직접 열지 않습니다.

    이 도구가 지키는 경계
    • 결제 · 카드/계좌 · 인증번호 입력과 저장은 자동화하지 않습니다.
    • 예약처 화면 자동 입력은 결제 버튼 직전에서 멈춰 화면을 사람에게 넘깁니다.
    • 여권 잔여 유효기간이 기준에 못 미치면 자동 입력으로 진행하지 않고 차단합니다.
    • 검증에서 빠진 것은 자동으로 채우지 않고 확인 항목으로 남깁니다.

    확인된 구현과 이 데모의 한계

    원본에서 확인한 사실

    • 자유 텍스트에서 날짜 범위, 오전/오후 시각, 공항, 항공사, 예약처, 가격을 구조화된 주문서로 추출하고, 결과는 사람이 고칠 수 있는 폼으로 보여줍니다.
    • 여권 잔여 유효기간을 귀국일 기준 183일로 두고, 미달 시 차단(ERROR)으로 처리합니다. 다르면 183일 이상 213일 미만 구간은 경고로만 표시합니다.
    • 가는 날이 오는 날보다 늦거나, 왕복인데 오는 날이 없으면 차단하고, 공항 코드 사전에 없는 값은 경고로 표시합니다.
    • 표시 가격은 언제나 참고값 안내를 함께 내고, 결제는 사람이 직접 누르도록 고정 문구를 붙입니다.
    • 원본은 파이썬 3.10 이상, FastAPI 기반 로컬 웹 UI와 CLI를 함께 제공하고, 핵심 파싱·검증 로직에 단위 테스트를 두었습니다.

    이 데모가 다르게 동작하는 지점

    • 파싱·검증 규칙을 참고해 브라우저 단독 JavaScript로 다시 작성했습니다. 로직이 같다는 보장은 없으며, 원본 파이썬 코드를 복사하지 않았습니다.
    • 원본의 서버, 여권 이미지 OCR, 프로필 암호화 저장, 브라우저 자동 입력은 이 데모에 없습니다. 입력값은 새로고침하면 사라집니다.
    • 예약처 검색 URL은 흐름 설명용으로 만든 예시 형식이며, 실제 예약처의 검색 규격과 다를 수 있습니다.
    • 예시로 표시되는 가격과 인원수, 인물과 여권 정보는 모두 이 데모에서 만든 합성 값이며 실제 성적이나 효과를 나타내지 않습니다.
    • 사람과 실명, 회사명과 서비스명은 공개하지 않고 기능만 보여줍니다.
