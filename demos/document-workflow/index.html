업무 자동화 · 공개 포트폴리오

사건 자료 정리 · 컨셉 데모

이 화면은 자료 보관용 저장소를 바탕으로 새로 만든 컨셉입니다. 기존 자동화 제품의 구현 성과가 아닙니다.

메신저 캡처, 결제 내역, 진정서,한글 문서처럼 형태가 다른 자료를 한 건의 사건으로 모으고, 분류한 뒤 선택한 자료를 검토 메모로 모으고, 내부 검토일을 관리하는 흐름을 체험할 수 있게 만들었습니다. 이 화면의 모든 이름·금액·날짜·문구·자료 내용은 합성 예시이며 실제 사건과 무관합니다.

  • 접수 정보만 입력하면 사건 카드와 기한이 만들어집니다.
  • 자료를 분류하고 근거로 선택한 항목만 초안에 반영됩니다.
  • 외부 전송·파일 저장·서버 통신 없이 브라우저 안에서만 동작합니다.

이 데모가 재현한 업무 흐름

원본 저장소는 실행 코드가 아니라 사건 자료만 모아 둔 문서 저장소라서, 실제로 매일 반복되는 Lawyer 업무 절차를 순서대로 재구성했습니다.

  1. 1사건 접수의뢰인·사건 유형·금액을 입력하면 사건 카드와 예상 기한이 자동 생성됩니다.
  2. 2자료 분류각 자료의 분류(증거·참고·보류)와 검토 상태를 눌러 바꿉니다.
  3. 3→근거 선택초안에 넣을 자료만 체크합니다.
  4. 4문서 초안 생성선택한 자료가 빠짐없이 근거 목록에 반영된 초안 텍스트가 나옵니다.
  5. 5기한 체크절차 항목을 체크하며 진행 상황을 표시합니다.

1. 사건 접수

아래 값을 입력하고 등록하면 아래 사건 목록에 바로 추가됩니다. 입력값은 화면을 벗어나지 않습니다.

접수 1개월 뒤 내부 검토일을 표시하는 합성 예시입니다. 법정 기한 계산이나 법률 판단을 제공하지 않습니다.

2. 사건 목록과 기한 체크

사건을 누르면 아래 자료 분류와 초안 작업 대상이 그 사건으로 바뀝니다. 기한은 등록 시점부터 경과일이 계산됩니다.

3. 자료 분류와 근거 선택

분류 버튼은 누를 때마다 상태가 순환하고, 체크박스는 문서 초안에 넣을 근거를 고르는 용도입니다.

작업 사건: —

합성 자료 목록과 분류·검토 상태
근거 자료명 (합성) 구분 형태 분류 검토 상태

4. 문서 초안 생성

문서 종류를 고르고 초안을 만들면, 위에서 근거로 체크한 자료만 인용 목록에 들어가 다른 항목은 빠짐없이 제외됩니다.

아직 생성된 초안이 없습니다. 사건을 선택한 뒤 ‘초안 만들기’를 누르세요.

실제 구현과 이 데모의 차이

원본 저장소에서 확인된 것

  • 사건별로 자료를 하위 폴더로 나눠 모아 두는 문서 저장소 형태로 보입니다.
  • 문서 종류가 여러 갈래입니다. .docx 문서, .jpg / .png 이미지, .xlsx 표, .hwp 문서, .zip 묶음 파일이 함께 들어 있습니다.
  • 폴더 이름과 파일 이름에 사건·단계 같은 식별자가 붙어 있어, 다시 찾을 때 사람이 이름을 맞춰 봐야 합니다.

이 데모가 실제 대신 한 부분

  • 원본에 실행 코드나 서비스 설정이 없어, 이 화면의 분류·초안·기한 규칙은 데모용으로 새로 정의했습니다.
  • 파일 열기, OCR, PDF 변환, 전자소송송달 같은 실제 처리 단계는 넣지 않았습니다. 자료는 이름만 있는 목록으로만 다룹니다.
  • 기한은 접수 1개월 뒤 내부 검토일을 표시하는 화면 예시입니다. 실제 사건의 법정 기한과 관계가 없습니다.
  • 데이터는 새로고침하면 사라집니다. 서버 저장, 계정, 권한, 감사 기록이 없습니다.

모든 입력·분류·초안·체크 상태를 처음 합성 데이터로 되돌립니다.
