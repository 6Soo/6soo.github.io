여행 수행 도구 모음: 붙여넣은 글 → 일정표와 좌석표

여행대장으로 받은 안내 메시지를 손으로 옮겨 적는 대신, 붙여넣은 텍스트를 일정표로 바꾸고 차량 좌석 배치도에 바로 이름이 올라가는 흐름을 묶어 만든 정적 웹 도구 모음을 재현했습니다. 외부 API 호출, 업로드, 전송, 저장 없이 브라우저 안에서만 동작합니다.

  • HTML · CSS · 순수 JavaScript
  • 정적 호스팅 (GitHub Pages)
  • 텍스트 규칙 파싱
  • DOM 기반 좌석 배치도

이 화면의 모든 이름, 여권 문자열, 차량 번호, 일정 내용은 합성 데이터입니다. 실제 고객·탑승자·여권 정보가 아니며, 입력한 내용은 새로고침하면 사라지고 서버로 나가지 않습니다.

1. 일정 파서: 어수선한 텍스트를 일정표로

날짜 머리말, 시간만 적힌 줄, 숙박 표기, * 메모가 섞인 원문을 붙여넣으면 규칙으로 분리해 날짜별 항목 목록을 만듭니다. 아래는 실제 변환 로직을 그대로 쓰는 데모입니다.

변환 결과

왼쪽에 원문을 넣고 일정 변환을 누르세요.

2. 차량 좌석 배치도: 이름을 올리면 배정 집계가 갱신

차종마다 다른 좌석 배치(전륜 2인승 10개석, 우측 통로형 24·28인승, 좌측 통로형 40인승)를 따로 정의하고, 운전석·출입문·냉장고 같은 고정시설과 승객 좌석을 구분합니다. 승객 좌석을 클릭하면 이름 입력창이 열립니다.

FRONT · 운전석 방향

배치도 캡처와 기기 공유 시트 연동, 좌석 이미지 미리 생성이 원본 도구의 실제 기능입니다. 이 데모에서는 캔버스 캡처 대신 공유 텍스트 미리보기만 만들어 보여 줍니다.

3. 여권 문자열 판독: MRZ 두 번째 줄만으로도 이름 읽기

여권 사진 인식 결과에서 machine readable zone 텍스트만 떼어 낸 상황을 흉내 냅니다. 원본 도구는 둘째 줄이 잘려 있어도 이름·여권번호·생년월일·성별·만료일을 읽어 주고, 항공권 화면 문자열을 여권으로 착각하지 않도록 방어 로직을 함께 둡니다. 아래에서도 같은 검증을 직접 돌려 볼 수 있습니다.

공개 저장소의 소스 파일만 읽고 정리한 내용입니다. 회사명과 운영 주소는 비식별 처리했습니다.

원본 저장소 상대경로 기준 확인 항목
상대경로 확인한 동작
script.js 차종별 좌석 타입(승객·운전석·출입문·냉장고·통로)을 배열로 정의하고, 빈 칸 클릭 시 좌석 추가, 이름 없는 좌석은 우클릭/더블클릭으로 제거하며, 좌석·차종 변경 때마다 공유용 미리보기 이미지를 백그라운드에서 다시 만듭니다.
parse-rules.js 일정 파싱 규칙을 별도 파일로 분리해 둡니다. 구분선 줄 무시, 여러 형태의 날짜 머리말 패턴, 시간만 적힌 줄과 다음 줄 병합, 숙박 표기 추출, * 시작 메모 처리 규칙이 있습니다.
mrz.js 여권 machine readable zone 파서를 두고, 둘째 줄이 잘린 입력에서도 이름을 복원하며 항공권 화면 문자열은 null 로 거절합니다.
tests/mrz-visual.test.js node 표준 assert 로 된 검사 스크립트가 있어, 잘린 둘째 줄·노이즈 낀 구형 여권·항공권 오인 방어를 각각 단언으로 확인합니다.

원본 저장소는 여러 사람이 누적 운영한 정적 도구 모음입니다. 이 데모는 개인이 처음부터 만든 결과물이 아니라, 원본 도구의 구조를 참고해 공개 설명용으로 다시 만든 것입니다. 회사명과 운영 주소는 비식별 처리했습니다.

데모와 실제 구현의 차이

  • 이미지에서 글자를 읽는 OCR, 여권·항공권 사진 판독은 브라우저에서 재현하지 않았습니다. 이 데모는 텍스트를 직접 입력하는 단계만 다룹니다.
  • 일정 파싱 규칙은 원본의 규칙 파일을 참고해 핵심 패턴(날짜 머리말, 시간 줄 병합, 숙박, 메모)만 간략화했습니다. 원본이 다루는 변형은 더 많습니다.
  • 좌석표 이미지 캡처와 기기 공유 시트 연동, 메신저로 공유하기 진입은 이 데모에서 동작하지 않습니다. 공유 버튼은 공유 문구 텍스트만 미리 보여 줍니다.
  • 원본 저장소의 문서에는, 정적 호스팅에서는 모델을 직접 부를 수 없어 업무 보드 분석을 로컬 보조 서버로 돌리는 방식이 적혀 있습니다. 이 데모에는 그 부분 (모델 호출, 캡처 전송)을 넣지 않았습니다.
  • 예약·결제·메일·메신저 전송, 실제 파일 저장, 데이터베이스 쓰기는 하지 않습니다. 입력 내용은 새로고침하면 모두 사라집니다.
  • 이름·여권 문자열·차량 번호는 전부 예시용 합성 데이터이며 실제 인물이나 문서와 무관합니다.
