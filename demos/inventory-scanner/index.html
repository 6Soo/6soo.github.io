업무 자동화 · 로컬 파이프라인

게임 화면을 읽어 목록으로 바꾸는 로컬 스캐너

아이템 목록이 창고 화면 안에만 존재하면 판매 판단과 정리가 모두 수동 작업이 됩니다. 이 프로젝트는 화면 캡처로 슬롯을 하나씩 읽고, OCR로 텍스트를 뽑고, 파서로 옵션을 정리한 뒤 점수와 판정을 붙여 결과 저장소로 모으는 로컬 파이프라인을 구성했습니다. 이번 화면에서는 그 흐름을 브라우저 안에서 그대로 재현합니다.

아래 데모의 모든 아이템, 옵션 수치, 로그, 해시 값은 화면에서 생성한 합성 데이터입니다. 실제 게임 화면이나 외부 서비스에는 접근하지 않고, 입력 값도 어디로도 전송되지 않습니다.

스캔 흐름 체험

창고 한 페이지를 스캔해 결과를 만든 뒤, 슬롯을 바꿔 diff 스캔이 무엇을 건너뛰는지 확인합니다.

기준 미만 점수는 OCR 처리 후 캡처 이미지를 삭제하는 규칙입니다. 입력은 이 화면에서만 쓰입니다.

파이프라인 진행 단계

    처리 통계

      처리 로그

      스캔 결과 (현재 페이지)

      슬롯 아이템 등급 옵션 퍼센타일 점수 유동성 판정

      점수는 롤 값이 최댓값 대비 몇 퍼센트인지를 평균 낸 값과, 아이템 이름·등급으로 얻는 기본 점수 중 큰 값을 씁니다. 두 계산 방식 모두 원본 가치 평가 모듈의 규칙을 그대로 옮긴 것입니다.

      원본에서 확인한 구현

      슬롯 스캔 워커

      슬롯 좌표로 마우리를 옮기고 지연을 둔 뒤 툴팁 영역을 캡처하고, 전처리, 파싱, 평가를 순서대로 수행합니다.

      이미지 보관 규칙

      OCR 처리 후 일반 캡처는 삭제하고, 가치 점수가 기준을 넘은 아이템 이미지와 슬롯 해시 스냅샷만 남깁니다.

      diff 스캔

      슬롯 위치와 해시로 스냅샷을 만들고, 해시가 같은 슬롯은 이전 결과를 재사용하고 바뀐 슬롯만 다시 처리합니다.

      안전한 입력 계층

      창고 페이지 이동은 클릭 대신 지정 키 입력으로 처리하며, 아이템 클릭과 드래그, 이동은 수행하지 않습니다.

      데모와 실제 구현의 차이

      • 이 화면은 캡처와 OCR을 실제로 수행하지 않습니다. 슬롯마다 합성된 텍스트를 미리 정해 두고 파싱·평가·저장 규칙만 재현합니다.
      • 해시 비교는 원본의 sha256 이미지 해시 대신 슬롯 내용으로 만든 결정적 값이라 실제 이미지 해시와 다릅니다.
      • 유동성 점수와 판정 문구는 데모에서 읽기 좋게 단순화했습니다. 실제 판정은 동일 점수·동일 기준 코드를 재사용합니다.
      • 마우스 이동, 지연 대기, 캡처 지연은 실제 시간 대신 화면 갱신으로 대체했습니다.
      • 캘리브레이션 파일, 창고 이동 키 설정 같은 실행 환경 설정은 공개하지 않고 설명만 옮겼습니다.
      • 저장은 브라우저 메모리에서만 이루어지며 새로고침하면 초기화됩니다. 서버나 데이터베이스로 전송되지 않습니다.

      공개 범위 메모

      이 화면은 공개 포트폴리오를 위해 같은 PC에서 동작하는 개인 프로젝트의 화면 흐름을 설명하기 위해 만들었습니다. 화면 처리 순서와 점수 계산 규칙은 원본 코드에서 확인한 내용만 옮겼고, 운영 환경 설정, 실제 수집 결과, 계정 정보는 포함하지 않았습니다. 회사명과 서비스명은 비식별 처리했습니다.
